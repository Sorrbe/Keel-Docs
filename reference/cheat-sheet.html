Cheat sheet ​

Before writing a helper, a check or a small utility, find it here. Each row maps a need to the one place that already does it. Use or extend that; never write a second copy.

Copy a plain-data table, or fill in missing keysTable.deepCopy, Table.reconcile
Static game data, cross-references, game-wide valuesDefs.kind, Defs.Boot, Shared/Defs/Rules
