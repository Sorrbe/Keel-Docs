Troubleshooting ​

Find the symptom, then the cause and fix.

Nothing boots ​

No [Loader] Server booted or [Loader] Client booted line ​

  • Script Sync is not connected to one or more of the six root Folders, or the Folder names do not match. See Connect Roblox Studio.
  • Check the Output for an error above the missing line: a boot error stops everything after it.

The boot stops with an error naming dependencies ​

The Loader stops the boot for: a dependency cycle (Loader: dependency cycle: A -> B -> C -> A), a Dependencies name no module has (usually a typo), a module with no Name or two with the same Name, an Hz that is not a positive number, or Dependencies that is not a list. Fix the module named in the message.

PreRender runs only on the client ​

A server module (a Service or System) has a PreRender method. The server never renders, so there is nothing to call it before. Move camera or visual work to a Controller; for per-frame server work before physics use PreSimulation, or Update with Hz for game logic.

Init waited ​

A module's Init waited. Init must not wait or call other modules. Move the work to Start or task.spawn. The rest of that Init still runs later.

… waited, so it was stopped (Scheduler) ​

An Update, PreSimulation or PreRender waited (the message names which). That hook is removed from the Scheduler, because every call would otherwise leave another paused copy running. Put waiting work in task.spawn.

One module failed but the game still runs ​

By design. A module that errors while loading, in Init or in Start is skipped from then on, and modules depending on it get a warning. Fix the first error in the Output.

Script Sync and the editor ​

The Keel Setup button isn't in Studio ​

The plugin must be in Studio's Plugins folder (Plugins tab, Plugins Folder) as KeelSetup.lua, and Studio must be restarted after copying it. Copy it from tools/KeelSetup.lua in your game.

The Folders exist but nothing syncs ​

Creating the Folders is not enough: each one must be connected to its disk folder with Script Sync, Sync with Directory, Keep Disk. The plugin's checklist shows the disk folder for each. See Connect Roblox Studio.

I reopened my place and the sync is gone ​

Script Sync connections are not stored in the place file, so they do not travel with a copied or re-saved place. Reconnect the six Folders. (A template place with the connections pre-made was tried and does not work.)

A new folder isn't in Studio ​

A folder with only a .gitkeep does not sync. Add a .luau file to it.

Errors open a copy of my script that I can't keep ​

You put client code in StarterPlayerScripts, which is cloned into each player. Client code belongs in ReplicatedFirst/Client.

Red underlines on correct code in VS Code ​

The Luau extension needs the sourcemap. Run node tools/sourcemap.js once, or reload VS Code. Instances that exist only in Studio (Workspace parts, Studio-built UI) are unknown to it.

StyLua rejects a file after a Windows clone ​

Keel 0.1.0 wrote CRLF line endings on Windows. 0.1.1 writes LF and adds a .gitattributes that keeps LF on checkout. Update to 0.1.1 or later.

Defs ​

Defs: N problem(s) found stops Studio from booting ​

Every problem is listed with its path, such as Items.sword_iron.Weapon: no Weapons entry "blde". In Studio any problem stops boot. On a live server the broken entry is disabled and logged instead, and so is any entry that referred to it.

My kind isn't registered ​

A kind in a module nothing requires is not registered. Keep Defs modules in Shared/Defs or Server/Defs, which Defs.Boot loads.

Networking ​

[Net] Bob sent Shop.Buy: arg 2: … (dropped) ​

Net rejected a client message before any handler ran: it failed a rate or argument check. It logs at most once per 10 seconds per player per message. If it is your own client, fix what you send.

An error saying a send must come from Start or later ​

A client sent before Net.WaitForServer() finished. Send from a Controller's Start, not from top-level code or Init.

The 257th message errors ​

A game can have 256 messages, Net's internal Keel.Ready included.

A request returns false, "timeout" / "no handler" / "error" ​

No answer within 10 seconds, no OnInvoke handler registered, or the handler errored or returned something other than (boolean, string?). A rejected one answers "invalid" or "rate limited".

Messages sent to a joining player seem lost ​

They are queued (up to 256) and delivered in order once the client calls Net.ClientReady(). If the client never gets that far, they never arrive. Check that the client boot completed.

Player data ​

A player is kicked on join ​

Data kicks instead of letting anyone play on empty data: no session could be started, a migration failed, the save is from a newer version than this server knows, or another server took the session. The reason is logged.

Nothing saves in Studio ​

Without API access, Studio uses ProfileStore's mock store. Turn API access on to test saving. FreshData = true also uses a throwaway store on purpose.

A value I changed doesn't appear on the client ​

Use Replica.Set. A direct write to Data.Get(player) is saved but not sent. See State and Replica.

Replica.Set errors ​

The path must be inside a replicated component, the value must be plain data (finite numbers, booleans, strings up to 255 bytes, tables of those, at most 8 deep), and the player's data must have loaded.

Purchases ​

The purchase prompt fails, or a subscription lookup logs HTTP 400 ​

The entry has a made-up Roblox id. Use testbuy and testpass in Studio until the real product exists in the Creator Hub.

testbuy errors ​

TestMode works in Studio only.

A product is never granted ​

The receipt answers NotProcessedYet when there is no Products entry for the ProductId, no OnProduct handler, the player's data is not loaded, or the handler errored, waited or returned false. Check the Output for the logged error.

Console ​

The console won't open ​

Press F2. Outside Studio only the UserIds in Server/Defs/Admins may use it.

Requiring Cmdr from the command bar fails ​

Do not. Cmdr moves its client folder on first require, so only Console may require it.

Tests and the command bar ​

My code change isn't seen by the tests ​

require caches modules for the whole playtest. Stop and start the playtest again.

A module I require from the command bar behaves oddly ​

The command bar and the Studio MCP get their own copy of every module. Call Net.WaitForServer() first in that copy.

Updating Keel ​

update says Keel files were edited ​

An owned file no longer matches its recorded hash. Move the change into the Keel repo, or run again with --force to discard it. See Update Keel.

update says there is no keel.json ​

The game was not created by keel.js new. Run node tools/keel.js update <tag> --force once to adopt it.
