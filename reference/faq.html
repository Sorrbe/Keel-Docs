FAQ ​

Setup and workflow ​

Why isn't Keel installed with Rojo, Wally or npm? ​

Keel is built for Roblox Studio's built-in Script Sync and GitHub only. Keel finds its own files at fixed paths (ReplicatedStorage.Keel, ServerScriptService.KeelServer), and server code must never reach clients, which a package folder cannot guarantee. tools/keel.js copies the files to the right places and records their hashes.

Can I edit Keel inside my game? ​

No. Owned files are replaced on every update, and update refuses (listing the files) if any were edited. Make the change in the Keel repo, tag a version, and update the game. See Releasing Keel.

How do I know which version a game has? ​

node tools/keel.js status, or read keel.json. Set the Version attribute on ReplicatedStorage and every client shows a small v<version> label, so bug reports name their build.

What does update touch? ​

Only owned files. Starter files (Shared/, Server/, ReplicatedFirst/, Boot/, CLAUDE.md, Docs/Start Here.md, ...) are copied once by new and are yours. See What gets created.

Can Script Sync be connected automatically? ​

No. Studio has no way to script Script Sync's "Sync with Directory", and the connections are not saved in the place file, so a pre-connected template place does not work either. The Keel Setup plugin creates the Folders and attributes and lists the six connects to make by hand. See Connect Roblox Studio.

A folder I created isn't showing in Studio. ​

A folder holding only a .gitkeep does not appear in Studio: Script Sync ignores non-script files. It appears when you add its first .luau file.

Code ​

Where does a new system go? ​

A server system is a Service in Server/Services/ (or Server/Systems/ for clock-driven work); a client system is a Controller in Client/Controllers/. Behaviour shared by players, NPCs and world objects is a component in Components/. See Architecture.

Why can't I send a message from the client? ​

A client may send a message only if it declares a Rate. A message without one is server-to-client only. See Networking.

Why is my Init erroring with "Init waited"? ​

Init must not wait or call other modules; that rule is what makes the boot order safe. Move the waiting work into Start, or into task.spawn.

Does Start wait for my dependencies' Start? ​

No. Starts are launched in dependency order, each in its own thread, so a Start that waits never holds back the others. If you need something a dependency sets up in its Start, wait for a Signal it fires.

Where do I put secret data (drop tables, odds)? ​

Server/Defs/. Anything in Shared/Defs/ is sent to every client.

How do I change a number without republishing? ​

Put it in Server/Defs and list its key in Server/Defs/LiveKeys, then set a ConfigService value. See Defs: live tuning. Values clients display need a publish.

Why doesn't my change to a player's data reach the client? ​

Write replicated state with Replica.Set. A direct write to the data table is saved but not sent. See State and Replica.

Why can't I save "owns VIP"? ​

Free trials and refunds end game-pass ownership without any event. Ask Roblox each time it matters with Purchases.OwnsPass. See Purchases.

Does Keel work with StreamingEnabled? ​

Yes. Keel assumes it is on (client components attach when a tagged model streams in and clean up when it streams out) and also works with it off.

Are there optional add-ons ("Kits")? ​

They are planned (ReplicatedStorage/Kits, ServerScriptService/KitsServer), but none are built yet.

Limits ​

How many network messages can a game have? ​

256, including Net's internal Keel.Ready. The 257th definition errors, because Packet ids are one byte.

How big can an unreliable message be? ​

Payloads over 900 bytes error at the sender.

How often does Keel autosave? ​

Every 60 seconds, plus a save on leave and on shutdown.

Testing ​

How do I run Keel's tests? ​

In a playtest, from the server command bar: require(game.ServerScriptService.KeelServer.Tests.Runner).Run(). See Unit tests.

Red errors scrolled past during the tests. Did they fail? ​

Some tests break things on purpose. Only [FAIL] lines count, and the run ends with [Tests] N passed, M failed.
