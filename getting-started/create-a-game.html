Create a game ​

Run keel.js new from the Keel checkout, giving it the folder for the new game.

sh
node tools/keel.js new ../MyGame

On success it prints one line:

text
keel: new game at C:\Projects\MyGame with Keel 0.2.0 (abc1234), 212 Keel files
keel: next, in Roblox Studio:
  1. Once per computer, copy tools/KeelSetup.lua into Studio's Plugins folder (Plugins tab, Plugins Folder), then restart Studio.
  2. Open a place and press the Keel Setup button: it creates the Folders and lists the six Script Sync connects to make.
  3. Press Play and look for [Loader] Server booted and [Loader] Client booted.

(The version, commit and file count change with each release.)

Arguments ​

text
node tools/keel.js new <dir> [tag] [--from <path>]
ArgumentMeaning
<dir>The folder for the new game. It must be empty or missing; otherwise the command stops with … is not empty.
[tag]A Keel version such as v0.1.1. Left out, keel.js asks GitHub for the newest v* tag. It stops with the Keel repo has no version tags yet if there is none.
--from <path>Use a local Keel checkout instead of cloning from GitHub. Useful to try changes before a tag exists.

Examples:

sh
node tools/keel.js new ../MyGame             # newest tagged Keel
node tools/keel.js new ../MyGame v0.1.1      # a specific tag
node tools/keel.js new ../MyGame --from .    # the checkout you are standing in

What it does ​

  1. Gets the Keel source: your --from folder, or a shallow clone of the tag into a temporary folder (deleted afterwards).
  2. Reads keel.manifest.json from that source.
  3. Copies every owned file (the framework, its notes, tooling) and every starter file (the game's own entry points) into <dir>. Text files are written with LF line endings.
  4. Writes keel.json in the new game with the installed version, the commit and a hash of every owned file.

See What gets created for the full list, and keel.json for the lock file.

Next steps ​

sh
cd ../MyGame
git init

Then connect Roblox Studio: install the Keel Setup plugin (tools/KeelSetup.lua), press its button to create the Folders, make the six Script Sync connects it lists, and press Play.

Warning

new refuses a folder that already has files in it. To bring an existing game under Keel, see Update Keel.
