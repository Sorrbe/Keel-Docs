What gets created ​

keel.js new copies two kinds of files, listed in keel.manifest.json in the Keel repo.

KindMeaningChanges on update?
Owned by KeelThe framework, its notes, the tooling.Replaced. Never edit these in a game.
StarterThe game's own entry points and settings.Copied once by new, then yours. update never touches them.

Owned by Keel ​

Replaced on every update. A game never edits them.

  • src/ReplicatedStorage/Keel/: Signal, Trove, Log, Loader, Scheduler, Net, Defs, Entity, State, the client layer, and the vendored Packet and Trove.
  • src/ServerScriptService/KeelServer/: Data, Replica, Policy, Purchases, LiveDefs, Console (with vendored Cmdr and ProfileStore), and the unit tests.
  • Docs/Systems/Keel/: Keel's own notes.
  • tools/keel.js, tools/sourcemap.js.
  • tools/KeelSetup.lua: the Studio plugin that creates the Folders and attributes. Copy it into Studio's Plugins folder once; see Connect Roblox Studio.
  • The three hooks in .claude/hooks/ (luau-check.js, note-lookup.js, keel-guard.js) and the luau-layout and verify skills.
  • stylua.toml, selene.toml.

Starter files ​

Copied once, then the game's own.

  • src/ReplicatedStorage/Shared/, src/ServerScriptService/Server/, src/ReplicatedFirst/, src/StarterPlayer/
  • .claude/settings.json, .vscode/settings.json, .styluaignore, .gitignore, .gitattributes
  • CLAUDE.md, Docs/Start Here.md, Docs/Status.md

Tip

Folders that hold only a .gitkeep (such as Server/Services/) exist on disk so Git keeps them, but Script Sync ignores non-script files, so they do not appear in Studio until you add the first .luau file. That is expected, not a sync problem.

Where each side starts ​

  • Server: Server/Main.server.luau, the only server Script. See Folders and boot.
  • Client: Boot/Boot.local.luau, which loads ReplicatedFirst/Client/Main.luau.
