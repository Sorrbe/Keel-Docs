Folders and boot ​

How the code is laid out on disk and in Studio, and how each side starts.

The Keel Setup plugin creates these Folders for you. How to install it and connect them: Connect Roblox Studio. The file-name rules (.server.luau, .local.luau, init.luau) are on that page too.

Note

Empty folders hold a .gitkeep because Git does not keep empty folders. Script Sync ignores non-script files, so a folder with only a .gitkeep does not appear in Studio until its first .luau file is added. Delete the .gitkeep once the folder has real files.

Boot ​

Both sides boot through the Loader.

Server ​

Server/Main.server.luau is the only server Script. In order, it:

  1. Requires Shared/Net, Keel/State/Messages and Keel/Purchases/Messages, so every network message exists before any client asks.
  2. Calls Defs.Boot on Shared/Defs and Server/Defs. In Studio a broken entry errors here and stops the boot.
  3. Calls the Configure of the services that need the game's settings: Data.Configure (test places and migration steps), LiveDefs.Configure (live-config keys), Purchases.Configure (products, passes, subscriptions) and Console.Configure (the admin list).
  4. Calls Loader.Boot("Server", KeelServer, Server.Services, Server.Systems). All are booted together and sorted by Dependencies, so a game Service can depend on a KeelServer one. A folder missing in Studio is skipped.
  5. Calls Entity.Boot(Server.Components), which starts attaching components to tagged Instances.

Client ​

  1. Boot.local.luau waits for game.Loaded.
  2. It requires ReplicatedFirst.Client.Main and calls Start().
  3. Main.Start() requires Shared/Net and Keel/Purchases/Messages, calls Defs.Boot on Shared/Defs, and calls Net.WaitForServer(), which waits until the server has published every message. (Loading.local.luau, an early LocalScript, has already shown the loading screen.) Then UIController.Boot registers every View.
  4. It calls Loader.Boot("Client", Client.Controllers). Then Entity.Boot(Client.Components).
  5. It calls State.Boot(), then Net.ClientReady() (the server sends anything it held back for this player), then Console.Start(), and last LoadingScreen.Hide().

Warning

Nothing in ReplicatedFirst may run networking before boot. The networking library does not work if started from ReplicatedFirst that early. Only the loading screen runs early.
