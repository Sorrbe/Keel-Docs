Console ​

An in-game admin console (built on Cmdr) for testing and moderation, and per-tag log switches.

FileWhat it is
KeelServer/Vendor/Cmdr/Cmdr, vendored unchanged apart from two directive lines per file
KeelServer/Console/Cmdr.luauthe one place that requires Cmdr
KeelServer/Console/init.luauserver Service (Console, depends on Replica and Policy): the permission rule, registering commands, mirroring Account.Admin
KeelServer/Console/Commands/Keel's commands: one Cmdr module per command, plus a …Server module for the part that runs on the server
KeelServer/Console/Types/Cmdr argument types
Keel/Client/Console.luauclient half: binds F2 and enables the window only while Account.Admin is true
Server/Defs/Admins.luauthis game's admin UserIds (server only)

Who may use it ​

  • Studio: everyone.
  • Any other server: only the UserIds in Server/Defs/Admins. A Cmdr BeforeRun hook refuses everyone else, whatever the client does. The client window is only a convenience.

Commands ​

Open the console with F2.

CommandWhat it does
log <tag> <on|off|only>mutes or restores a tag's Info lines on the server and every client (Warn and Error are never muted). only mutes every other tag; the tag * means all (log * off, log * on)
policyprints the Roblox policy flags your client has
testbuy <product> [times]Studio only: a pretend developer-product purchase; with times above 1 the same receipt is sent again each time
testpass <pass> <on|off|clear>Studio only: pretend you own (or do not own) a pass; clear goes back to asking Roblox
livedefslists the server-only Defs values that live configs have changed

Cmdr's own groups are registered too (kick, ban, announce and the rest of DefaultAdmin, DefaultDebug, DefaultUtil, Help).

Adding a command ​

Add Commands/name.luau (returns Cmdr's definition table: Name, Description, Group = "Keel", Args) and, if it must run on the server, Commands/nameServer.luau (returns function(context, ...) that returns a string). No other change is needed.

Autocomplete from Defs: a module in Console/Types/ returning function(registry) CmdrType(registry, "product", "Products") end makes an argument type that suggests the ids of a Defs kind. A command argument then says Type = "product". The client has only the shared kinds: for a server-only kind it suggests nothing and accepts any text, and the server still rejects an id that does not exist when the command runs. See CmdrType.

Log switches ​

Log reads a string attribute LogOff on ReplicatedStorage: tags to mute, comma separated (Data,Replica); * mutes every tag and -Name exempts one (*,-Replica keeps only Replica). It is read when Log loads and followed live; it replicates, so setting it on the server mutes the tag on every client. Set it in the Properties panel, or with the log command. Info never prints outside Studio anyway.

Warning

Cmdr moves its CmdrClient folder into ReplicatedStorage when first required (Console does that in Init). Do not require the vendored Cmdr from anywhere else, and do not require it from the command bar: it would run a second copy and fail.

See the Console (server) and Console (client) API pages.
