Fields ​

The field types a Def's shape is built from, each with its own check.

Shared src/ReplicatedStorage/Keel/Defs/Fields.luau

luau
local Fields = require(ReplicatedStorage.Keel.Defs.Fields)

Overview ​

A kind's shape lists what every entry must contain (Price = Defs.Int(0), Weapon = Defs.Ref("Weapons")). Each Field knows how to check a value, so a typo or a wrong-shaped entry is reported at boot.

  • Owns: the Field builders and the checks. Pure: no registry, no state.
  • Called by: Keel/Defs (which re-exports the builders as Defs.Int, Defs.String, ...).
  • Fires: nothing.

Usage ​

A Field is { Check = function(value, refs?) -> reason?, Optional = boolean }. Check returns nil when the value is fine, otherwise a short reason. Reasons from List and Struct carry a path: [3]: must be at least 0 or Cost.Cash: is required. refs(kind, id) answers whether a cross-reference exists: nil if it does, otherwise the reason it doesn't. Only Ref needs it (Defs passes it; Net doesn't).

Keel/Net/Args builds on these: a Net argument type is a Field plus its Packet encoding, so the checks live only here. Add a new check type here, not there. Shared helpers: IsFinite, CheckRange(min, max, label, level) and ValuesOf(values, label).

luau
String(maxLength?)      string, at most maxLength bytes if given
Number(min?, max?)      finite number, in range if given
Int(min?, max?)         whole number, in range if given
Bool()                  true or false
OneOf({ "a", "b" })     one of a fixed set of strings
Ref(kindName)           the id of an entry of another kind (checked against that kind)
List(field, maxLength?) list of values, each checked by field
Struct({ key = field }) table with exactly these keys, each checked
Optional(field)         the same field, but the value may be nil
PlainData()             nil, or plain data safe to save and to send: finite numbers, booleans, strings of
                        at most 255 bytes, and tables of those (string or number keys, at most 8 deep)

Builders error at definition time on bad parameters (a code mistake).

Notes ​

Fields is the one home of check logic. Net.Args builds its argument types on these (a Net argument is a field plus the Packet type that encodes it), so never write a second copy of a check elsewhere. A new kind of check goes here.
