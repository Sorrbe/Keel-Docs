CmdrType ​

Makes a console argument type that suggests the ids of a Defs kind.

Shared src/ReplicatedStorage/Keel/Defs/CmdrType.luau

luau
local CmdrType = require(ReplicatedStorage.Keel.Defs.CmdrType)

Overview ​

A console command that takes a product, a pass or any other Defs id can offer the real ids as you type instead of a free-text box. One line per kind, so a new command argument costs nothing.

  • Owns: nothing. Pure: reads the Defs registry when it is asked, so it always sees the current ids.
  • Called by: the type modules in KeelServer/Console/Types (Cmdr runs them on the server and, because it sends them to clients, on every client too).
  • Fires: nothing.

Usage ​

luau
-- KeelServer/Console/Types/product.luau
return function(registry)
	CmdrType(registry, "product", "Products")
end
-- then a command argument can say Type = "product"

Suggestions and checking use whichever Defs the side running the type has. The client has only the shared kinds, so for a server-only kind it can't suggest anything and accepts any text; the server, which has every kind, still rejects an id that doesn't exist when the command runs.

Signature ​

This module returns a single function, not a table:

luau
CmdrType(registry: any, typeName: string, kindName: string)

It registers a Cmdr type that validates text against Defs.IdsOf(kindName) (a side with no such kind accepts any text), autocompletes with a fuzzy finder over those ids, and parses to the text itself.

Example ​

luau
-- KeelServer/Console/Types/product.luau
local CmdrType = require(ReplicatedStorage.Keel.Defs.CmdrType)

return function(registry)
	CmdrType(registry, "product", "Products")
end
