API Reference ​

One page per Keel module, generated from the Luau source by npm run gen:api. Signatures, types and header text come straight from the code; parameter descriptions and examples come from site/api-notes/.

Core ​

ModuleWhat it does
SignalTyped event objects (e.g. Health.Died).
TroveA cleanup bag for connections, instances, threads and functions.
LogTagged logging.
TypesShared Keel types, in one place to import from.
TableSmall helpers for plain-data tables.
SettingReads a place attribute, falling back to a default written in the script.
GuardCalls a function safely, for code that must not stop its caller.

Boot ​

ModuleWhat it does
LoaderBoots Services, Controllers and Systems.
SchedulerRuns every module's repeating work from one connection per frame phase.
ModulesFinds the ModuleScripts a boot step should load.

Game data ​

ModuleWhat it does
DefsTyped game data (what things ARE), checked at boot.
FieldsThe field types a Def's shape is built from, each with its own check.
CmdrTypeMakes a console argument type that suggests the ids of a Defs kind.
ShapesThe Defs shapes for things sold for Robux.

Entities ​

ModuleWhat it does
EntityThings with identity and behaviour, built from components.

Networking ​

ModuleWhat it does
NetDefines network messages and sends them, checked and rate-limited.
Net ArgsArgument types for network messages, each with its own check.
Net ScreenThe server's check of every message a client sends.

State ​

ModuleWhat it does
StateThe client's one way to read replicated state.
PathDot paths into a table of plain data ("Currency.Cash").
StoreOne subject's state on the client, with observers.

Client ​

ModuleWhat it does
InputBinds actions to keys, buttons and touch.
ViewOne screen or menu.
UIControllerOpens and closes Views by name.
WidgetA reusable piece of UI (an item slot, a progress bar, a currency label, a popup).
Console (client)Opens the Cmdr console window for admins.
Purchases (client)What a shop screen needs to offer things for Robux.

Server ​

ModuleWhat it does
DataPlayer data saving, on ProfileStore.
MigrationsUpgrades an old-shaped save to the current shape.
ReplicaSends each player's state to the clients allowed to see it.
PolicyWhat Roblox's policy lets each player do, and where they are.
Purchases (server)Selling things for Robux without granting twice, losing a purchase, or breaking policy.
LiveDefsChanges chosen server-only game values on running servers, without a publish.
Console (server)The admin / developer console (Cmdr) and who may use it.
