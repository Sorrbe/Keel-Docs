Input ​

Binds actions to keys, buttons and touch.

Client src/ReplicatedStorage/Keel/Client/Input.luau

luau
local Input = require(ReplicatedStorage.Keel.Client.Input)

Overview ​

Game code says what the player does ("Interact") and Input maps it to keyboard, gamepad and touch in one place, so no Controller reads keys directly and a rebind or a new device never touches game logic.

  • Owns: the list of bound actions. A thin wrapper on ContextActionService.
  • Called by: Controllers and Views.
  • Fires: the handler you pass, with true when the action begins and false when it ends.

Usage ​

luau
local binding = Input.Bind("Interact", {
	Keyboard = Enum.KeyCode.E,
	Gamepad = Enum.KeyCode.ButtonX,
	Touch = true,        -- also creates an on-screen button
	Title = "Use",       -- the touch button's text (optional)
}, function(began: boolean) ... end)
binding:Unbind()          -- or Input.Unbind("Interact")

A bound action takes the input (the key does nothing else while it is bound). Binding an action name twice errors: a rebind should be deliberate, so Unbind first.

Input.Bind ​

luau
Input.Bind(action: string, keys: Keys, handler: (began: boolean) -> ()): Binding

Binds an action to keyboard, gamepad and/or touch (wraps ContextActionService). A bound action takes the input: the key does nothing else while bound.

luau
local binding = Input.Bind("Interact", {
	Keyboard = Enum.KeyCode.E,
	Gamepad = Enum.KeyCode.ButtonX,
	Touch = true,
	Title = "Use",
}, function(began)
	if began then
		ShopController.Open()
	end
end)

binding:Unbind()

Parameters

NameTypeDescription
actionstringThe action's name. Binding the same name twice errors; unbind first.
keysKeysA table with any of Keyboard (an Enum.KeyCode), Gamepad (an Enum.KeyCode), Touch (true for an on-screen button) and Title (the touch button's text).
handler(began: boolean) -> ()Called with began: true when the input starts, false when it ends.

Returns Binding — a Binding. Call binding:Unbind() to remove it.
