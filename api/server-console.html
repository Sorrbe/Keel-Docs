Console (server) ​

The admin / developer console (Cmdr) and who may use it.

Server src/ServerScriptService/KeelServer/Console/init.luau

luau
local Console = require(ServerScriptService.KeelServer.Console)

Overview ​

Lets the owner and moderators run commands in a live or test game (switch a log tag off, give a test purchase, check a player's policy, kick someone) from an in-game console, without publishing a change. It can do powerful things, so it is locked down.

  • Owns: the Cmdr instance, which commands exist, and the rule for who may run them.
  • Called by: Server/Main (Console.Configure with the admin list, before Loader.Boot); the client half (Keel/Client/Console) opens the window.
  • Fires: nothing.

Usage ​

A Service booted by the Loader (Name "Console", depends on Replica and Policy).

luau
Console.Configure({ Admins = { userId, ... } })   -- once, before Loader.Boot
Console.CanUse(isStudio, admins, userId)          --> boolean (the rule, for tests)

Who may use it: in Studio, everyone. On any other server, only the UserIds in Admins; everyone else is refused by a Cmdr BeforeRun hook, whatever their client does (Cmdr also refuses to run anything on a live server that has no such hook). The player's own answer is mirrored to Account.Admin so their client knows whether to enable the window.

Commands: Cmdr's own groups (DefaultAdmin, DefaultDebug, DefaultUtil, Help) plus Keel's, one Cmdr module per command in Console/Commands (a name ending in Server runs on the server). Cmdr moves each command module out to its client folder when it registers them. To add a command, add a pair of files there; no other change is needed.

Console.CanUse ​

Console.CanUse(isStudio: boolean, admins: { number }, userId: number): boolean

The permission rule, as a pure function so it can be unit-tested.

Parameters

NameTypeDescription
isStudiobooleanWhether this server is Studio.
admins{ number }The list of admin UserIds.

Returns boolean — true in Studio for everyone, otherwise only if userId is in admins.

Lifecycle ​

This module is a Service booted by the Loader. The Loader calls these; game code does not.

  • Console:Init()
  • Console:Start()

Behaviour ​

  • Studio: everyone may use the console. Any other server: only the listed UserIds. A Cmdr BeforeRun hook enforces it, whatever the client does.
  • The Service registers Cmdr's groups (DefaultAdmin, DefaultDebug, DefaultUtil, Help) and Keel's commands (log, policy, testbuy, testpass, livedefs), mirrors Account.Admin to the client, and publishes the log tags for autocomplete.
  • It is the only module that may require Cmdr; do not require the vendored Cmdr anywhere else.
