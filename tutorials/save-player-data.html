Save and show player data ​

You will give every player saved cash, charge it when they buy something, and show it on a HUD that updates by itself.

You need the Shop kind, the Shop.Buy message, ShopService and ShopController from the previous tutorials.

1. A saved component ​

A component declares its own saved shape. Create Server/Components/Currency.luau:

luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local Entity = require(ReplicatedStorage.Keel.Entity)
local Rules = require(ReplicatedStorage.Shared.Defs.Rules)

return Entity.component({
	Name = "Currency",
	Saved = true,
	Audience = "Owner",
	Default = { Cash = Rules.StartingCash },
})
  • Saved = true puts Currency in every player's save, starting from Default.
  • Audience = "Owner" sends it to that player only (cash is private). The other choices are "Public" (everyone) and "None" (server only).
  • Rules.StartingCash is a value from Shared/Defs/Rules.luau.

There is nothing else to register. Server/Main boots the Components/ folder, and Data builds each player's save template from every Saved component.

2. Charge for the purchase ​

Update ShopService to check and spend the player's cash. Replace its contents:

luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local ServerScriptService = game:GetService("ServerScriptService")

local Log = require(ReplicatedStorage.Keel.Log)
local Messages = require(ReplicatedStorage.Shared.Net)
local Shop = require(ReplicatedStorage.Shared.Defs.Shop)
local Replica = require(ServerScriptService.KeelServer.Replica)

local log = Log.new("ShopService")

local ShopService = {
	Name = "ShopService",
	Dependencies = { "Replica" },
}

local function buy(player: Player, id: string)
	local entry = Shop.Get(id) :: any
	local cash = Replica.Get(player, "Currency.Cash") :: number?

	if entry == nil or cash == nil then
		return
	end

	if cash < entry.Price then
		log:Info(`{player.Name} can't afford {id}: has {cash}, needs {entry.Price}`)
		return
	end

	Replica.Set(player, "Currency.Cash", cash - entry.Price)
	log:Info(`{player.Name} bought {id} for {entry.Price}: cash now {cash - entry.Price}`)
end

function ShopService:Init()
	Messages.Shop.Buy:OnServer(buy)
end

return ShopService

Two things to notice:

  • The server decides. The client only said which item. The price comes from Shop, and the cash comes from the server's copy.
  • Replica.Set writes and replicates. Because Currency is saved, the same call changes the player's save. Never write the table directly: a direct write is not sent to the client.

3. Show it on a HUD ​

A View is one screen. Create src/ReplicatedFirst/Client/UI/Views/HUD.luau:

luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local View = require(ReplicatedStorage.Keel.Client.View)
local State = require(ReplicatedStorage.Keel.State)
local Trove = require(ReplicatedStorage.Keel.Trove)
local Shop = require(ReplicatedStorage.Shared.Defs.Shop)
local ShopController = require(script.Parent.Parent.Parent.Controllers.ShopController)

local ITEM = "pistol"

local function style(label: TextLabel | TextButton, position: UDim2, color: Color3)
	label.Size = UDim2.fromOffset(200, 36)
	label.Position = position
	label.BackgroundColor3 = color
	label.TextColor3 = Color3.new(1, 1, 1)
	label.TextSize = 18
	label.BorderSizePixel = 0
	local corner = Instance.new("UICorner")
	corner.CornerRadius = UDim.new(0, 8)
	corner.Parent = label
end

return View.new({
	Name = "HUD",
	Build = function(gui: ScreenGui, trove: Trove.Trove)
		local entry = Shop.Get(ITEM) :: any

		local cash = Instance.new("TextLabel")
		style(cash, UDim2.fromOffset(16, 16), Color3.fromRGB(30, 30, 36))
		cash.Text = "Cash: -"
		cash.Parent = gui
		trove:Add(State.Observe("Currency.Cash", function(value: any)
			cash.Text = `Cash: {tostring(value)}`
		end))

		local button = Instance.new("TextButton")
		style(button, UDim2.fromOffset(16, 60), Color3.fromRGB(46, 125, 214))
		button.Text = `Buy {entry.DisplayName} ({entry.Price})`
		button.Parent = gui
		trove:Add(button.Activated:Connect(function()
			ShopController.Buy(ITEM)
		end))
	end,
})

State.Observe("Currency.Cash", fn) calls fn now (once the value exists) and on every change. Putting it in the trove means it is cleaned up with the View. Update ShopController to open the View and drop the test send:

luau
local UIController = require(ReplicatedStorage.Keel.Client.UIController)

function ShopController:Start()
	UIController.Open("HUD")
end

Client/Main registers every View in UI/Views/ before the Controllers boot, so Open("HUD") already works in Start.

4. Play ​

Press Play. A cash label shows Cash: 100 and a button reads Buy Pistol (25). Click the button: cash drops to 75 and the server Output logs the purchase.

5. Check it saved ​

With Studio's API access on, stop the playtest and press Play again: the cash is what you left it at. To test as a brand-new player without touching real saves, set the attribute FreshData = true on ServerScriptService (Studio only).

Tip

Without API access, Studio uses ProfileStore's mock store and nothing is saved between runs. That is expected.

What you learned ​

  • A Saved component with an Audience gives you persistence and replication.
  • The server owns the value and writes it with Replica.Set; the client only watches it with State.Observe.
  • Views put every observer in the trove so nothing leaks.
