Add a network message ​

You will define a Shop.Buy message that a client may send, handle it on the server, and see how Net protects the handler.

You need the Shop kind from Define game data.

1. Define the message ​

Every message lives in one file: src/ReplicatedStorage/Shared/Net.luau. Replace its contents:

luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local Net = require(ReplicatedStorage.Keel.Net)
local Shop = require(ReplicatedStorage.Shared.Defs.Shop)

return {
	Shop = {
		Buy = Net.event("Shop.Buy", { Net.OneOf(Shop.Entries) }, { Rate = 5 }),
	},
}

Reading it left to right:

  • Net.event("Shop.Buy", …) is a fire-and-forget message named Feature.Action.
  • { Net.OneOf(Shop.Entries) } is the argument list: one argument, which must be the id of a Shop entry. The server therefore never sees an id that does not exist.
  • { Rate = 5 } lets a client send it at most 5 times per second. A message without a Rate cannot be sent by a client at all.

2. Handle it on the server ​

Create Server/Services/ShopService.luau:

luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local Log = require(ReplicatedStorage.Keel.Log)
local Messages = require(ReplicatedStorage.Shared.Net)

local log = Log.new("ShopService")

local ShopService = {
	Name = "ShopService",
}

local function buy(player: Player, id: string)
	-- Net has already checked the shape and the rate. Game rules (can they afford it?) are ours.
	log:Info(`{player.Name} asked to buy {id}`)
end

function ShopService:Init()
	Messages.Shop.Buy:OnServer(buy)
end

return ShopService

The handler receives the player first, then the arguments. Connect listeners in Init: the client's Controllers connect theirs in Init too, so nothing is missed.

3. Send it from the client ​

Create src/ReplicatedFirst/Client/Controllers/ShopController.luau:

luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local Messages = require(ReplicatedStorage.Shared.Net)

local ShopController = {
	Name = "ShopController",
}

function ShopController.Buy(id: string)
	Messages.Shop.Buy:FireServer(id)
end

function ShopController:Start()
	ShopController.Buy("pistol") -- temporary: a test send on startup
end

return ShopController

Controllers are the only client modules that send messages.

4. Play ​

Press Play. The server Output shows [ShopService] <your name> asked to buy pistol. Remove the test send from Start when you are done.

5. What Net did for you ​

Before buy ran, Net, on the server:

  1. checked the rate (a token bucket refilling 5 per second per player);
  2. checked every argument, and rejected extra values;
  3. only then called your handler.

A rejected message is dropped, with a warning at most once every 10 seconds per player per message:

text
[Net] Bob sent Shop.Buy: arg 1: … (dropped)

Your handler can rely on the shape. It still has to check game rules: can this player afford it, are they close enough, is it on cooldown.

What you learned ​

  • All messages live in Shared/Net.luau.
  • A client can send only messages that declare a Rate.
  • Net validates before any handler runs.
