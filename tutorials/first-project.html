Build your first project ​

In this tutorial you create a new game with Keel, connect it to Roblox Studio, see both sides boot, and add your first Service.

1. Create the game ​

From your Keel checkout:

sh
node tools/keel.js new ../MyGame
cd ../MyGame
git init

keel.js prints how many Keel files it installed. Open MyGame in your editor. You will see src/, Docs/, tools/ and keel.json. See What gets created.

2. Connect Studio ​

Open a new Baseplate in Roblox Studio. If you have not yet, copy tools/KeelSetup.lua into Studio's Plugins folder and restart Studio. Press Keel Setup to create the six root Folders, then connect each one to its disk folder, as described in Connect Roblox Studio.

3. See it boot ​

Press Play. The Output window shows:

text
[Loader] Server booted …
[Loader] Client booted …

Those two lines mean the Loader started everything on both sides. Stop the playtest.

4. Add your first Service ​

A Service is a module the Loader boots. Create src/ServerScriptService/Server/Services/HelloService.luau:

luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local Log = require(ReplicatedStorage.Keel.Log)

local log = Log.new("HelloService")

local HelloService = {
	Name = "HelloService",
}

function HelloService:Init()
	log:Info("init: wiring up, nothing to wait for")
end

function HelloService:Start()
	log:Info("start: every Init has finished")
end

return HelloService

Services/ held only a .gitkeep, so it was not in Studio before. Adding the first .luau file makes the folder appear. You can delete the .gitkeep.

Press Play again. In the Output window you should now see:

text
[HelloService] init: wiring up, nothing to wait for
[HelloService] start: every Init has finished

and the Loader's own lines, including [Loader] Init HelloService (… ms) and [Loader] Start HelloService.

Tip

Info lines print only in Studio. They cost nothing on a live server. Warn and Error always print.

What just happened ​

  • You put a ModuleScript in Server/Services/. Server/Main.server.luau calls Loader.Boot on that folder.
  • The Loader required your module, saw its Name, and called Init and then Start.
  • You did not register the Service anywhere. Folder membership is the registration.
